# 3-Minute Demo Script

## Flow A: Happy Path (2 min)

1. Open Flutter app and select provider (example: Aadhaar or Gusto).
2. Tap **Generate Proof** and wait for proof completion.
3. Show entry in Vault with `shareStatus=local_only`.
4. Tap **Upload + Share**.
5. Show QR and link.
6. Open link in desktop browser (or another phone browser) without app install.
7. Show green verification status and scoped claims.
8. Show signed verification receipt panel.

## Flow B: Failure Path (1 min)

1. In app, tap **Revoke** on the same proof share token.
2. Refresh recipient browser page.
3. Show blocked state (`revoked`).

## Judge Callouts

- Proof generated by zkTLS on mobile.
- Proof is encrypted at rest in app and backend.
- QR carries tokenized URL only, no raw proof.
- Server verifies proof cryptographically before rendering claims.
- Receipt contains hash + timestamp + signed verifier result.
